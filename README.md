# セロ貴族への道 — 体験型LP

## 起動方法
`index.html` をブラウザで開くだけで動作します。ビルドや npm install は不要です。

ローカルサーバーで確認する場合は、このフォルダー内で `python -m http.server 8000` を実行し、`http://localhost:8000` にアクセスしてください。

## 実装内容
- スマホ・タブレット・PC対応
- 3問のセロ貴族診断（娯楽用）
- 自然のバグ図鑑と2スポット紹介
- デモ用スタンプ帳（実際のGPS認証・クーポン発行なし）
- Googleマップへの検索リンク

## 公開前に必要な対応
1. `assets/` 内のAI生成コンセプト画像を、使用許諾を得た実際の現地写真に差し替える。
2. 主催者・施設・協力店舗との調整が完了するまでは、キャンペーンや特典を実施中と表記しない。
3. 公開先URLを確定した後、別途そのURLで本物のQRコードを生成し、ポスターに差し込む。
4. 実施する場合は、開催期間、運営者、プライバシーポリシー、参加条件などを追記する。
5. Google Fontsの読み込みにはインターネット接続が必要（未接続でも代替フォントで表示）。

この制作物は職業訓練グループワーク向けのコンセプトデモです。
